# 小说转 AI 短剧素材包

![小说转 AI 短剧素材包工作流](assets/readme/novel-to-ai-drama-pack-overview.png)

把一部完整小说整理成可以直接进入 AI 视频制作流程的短剧素材包。它会完整阅读原文、建立人物/场景/重要道具与菜肴资产库，输出用户指定集数的剧本和带 `@` 参考图引用的分镜提示词，并实际生成图片与 AI 配音素材。

> 这个 Skill **不生成视频文件**。它生成的是图片、声音、剧本、分镜和可直接交给视频工具的提示词。

## 能做什么

- 支持 TXT、Markdown、DOCX、EPUB、PDF 与粘贴的完整小说。
- 通读全文后再改编，建立世界观、时间线、伏笔、人物关系和分季分集规划。
- 为每个出镜角色制作一张综合设定图；主角和主要配角另有表情图、动作图与声音样音。
- 为使用到的场景、重要道具和剧情重要菜肴建立实际图片资产；普通生活小物件只写在文字里，不单独做图。
- 用户决定“写多少集剧本”和“做多少集样片素材”，两者可以不同。
- 所有分镜提示词都用句内资产引用，例如：

  ```text
  林岚@角色_C001_林岚_综合设定图_V001推门进入书房@场景_S003_林宅书房_综合设定图_V001，右手仍握着账册。
  ```

- 为前面指定的样片集数，实际生成每个镜头的一张示范画面，以及每句台词的 AI 声音文件。
- 为所有指定剧集输出视频生成提示词，但不代替用户调用视频模型生成视频。
- 用 `project.json` 管理唯一编号、版本、文件哈希、引用关系与制作进度，方便长篇作品断点续作。

## 资产原则

| 类型 | 是否生成图片 | 是否可在分镜中 `@` 引用 |
| --- | --- | --- |
| 角色 | 是 | 是 |
| 场景 | 是 | 是 |
| 重要武器、信物、证物、法器 | 是 | 是 |
| 剧情重要菜肴 | 是 | 是 |
| 杯子、钥匙、普通手机、普通书本等小物 | 否 | 否，只用文字描述 |

角色、场景、道具、菜肴、剧集与镜头都有固定编号。改名不改编号，重做时升版本，旧版不会被覆盖。

## 工作方式

1. 上传或提供完整小说。
2. Skill 复制原稿、计算 SHA-256、提取全文并核对首章和末章。
3. Skill 通读全书，建立故事圣经、全集规划和资产清单。
4. 在一次集中确认中确定视觉风格、剧本集数和样片集数。
5. 按依赖顺序生成风格图、人物图、场景图、重要道具/菜肴图、样片镜头图与声音。
6. 输出剧本、分镜提示词、声音清单、媒体清单和可交付的 Excel/Markdown 文件。

开始时只需说清楚你的目标，例如：

```text
用“小说转 AI 短剧素材包”处理这本小说。
想写 40 集剧本，先做前 2 集样片素材；画风选国风电影动画。
```

如果尚未确定集数或风格，Skill 会在完成全文分析后给出有依据的建议，再一次性确认。

## 安装

这是一个 Codex Skill。把仓库中的目录安装到本机 Skills 目录：

```bash
cp -R skills/novel-to-ai-drama-pack ~/.codex/skills/novel-to-ai-drama-pack
```

然后在 Codex 中直接说：

```text
使用小说转 AI 短剧素材包 Skill 处理我上传的小说。
```

安装后，Skill 会自行定位它的脚本目录，不依赖仓库当前路径。

## 交付内容

每个项目在工作区中独立保存，核心内容包括：

```text
项目名/
├── 00_原著文件/               # 原稿副本与提取全文
├── 01_小说解析/               # 世界观、时间线、伏笔、人物关系
├── 02_短剧规划/               # 分季、分集、章节对应
├── 03_人物数据库/             # 人物档案和声音档案
├── 04_人物综合设定图/         # 一人一张综合图；主角/主要配角另有表情、动作图
├── 05_场景数据库/
├── 06_道具与菜肴数据库/
├── 07_短剧剧本/
├── 08_AI视频分镜/             # 句内 @资产引用的中英文提示词
├── 09_样片镜头示范画面/       # 仅用户指定的样片集数
├── 10_角色声音与配音/         # AI 生成声音，非真人克隆
├── assets/                    # 版本化实际媒体文件
├── media-jobs.json            # 可续作的生成任务
└── project.json               # 唯一事实源
```

正式导出还会提供 `project.md`、`shots.xlsx`、`video-prompts.txt`、`media-manifest.json` 与 `validation-report.txt`。

## 质量门禁

- 不读完整本小说，不开始写分镜。
- 没有已登记的角色/场景/重要物品图片，不允许在 `@` 引用中假装存在。
- 每个 `@` 引用都必须能定位到登记的资产版本；普通小物不得滥用引用。
- 图片必须是真实生成、实际保存并校验哈希，不能以占位文件冒充完成。
- 声音使用 AI 内置声线，不克隆、模仿或冒充真人。
- API 密钥缺失时会诚实保留未完成声音任务，绝不伪造音频交付。
- 只有结构、引用、媒体与哈希均通过验证，项目才标为完成。

## 仓库结构

- `skills/novel-to-ai-drama-pack/`：可安装的 Skill。
- `references/`：全书改编、图片、声音与 `@` 引用规则。
- `scripts/`：提取、验证、生成任务清单、导出和断点续作工具。
- `tests/`：项目契约、引用、媒体任务、导出和回归测试。
- `smoke-projects/`：真实媒体文件的最小验证项目。
